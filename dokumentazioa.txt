1. SARRERA
================================================================================

ElorAdmin ikastetxe baten kudeaketa sistema bat da. Aplikazio honek erabiltzaileak kudeatzeko, ordutegiak ikusteko eta bilerak antolatzeko aukera ematen du. Lau rol desberdin daude: Superadmin (God), Admin, Irakaslea eta Ikaslea.

Proiektua bi zatitan banatuta dago: Frontend (Angular) eta Backend (Node.js + Express).

3. PROIEKTUAREN EGITURA
================================================================================

Proiektuak bi karpeta nagusi ditu:

BACKEND/ karpetan:
- src/entities/     --> Datu-baseko entitateak (User, Ciclo, Modulo, Horario, Reunion, Tipo, Matriculacion)
- src/routes/       --> API endpoint-ak
- src/index.ts      --> Zerbitzariaren sarrera puntua
- src/data-source.ts --> Datu-base konexioa

FRONTEND/ karpetan:
- src/app/pages/    --> Orrialdeak (login, home-god, home-admin, home-teacher, home-student)
- src/app/services/ --> Angular zerbitzuak API deietarako
- src/app/shared/   --> Konponente partekatuak (navbar, footer, centro-selector)
- src/assets/i18n/  --> Itzulpen fitxategiak (eu.json, es.json, en.json)

>> KAPTURA 4: phpMyAdmin-en datu-basearen taulak

================================================================================
5. BACKEND-A
================================================================================

Backend-ak REST API bat eskaintzen du. Express erabiliz, endpoint desberdinak sortu nituen:

- GET /api/users      --> Erabiltzaile guztiak lortu
- POST /api/users     --> Erabiltzaile berria sortu
- PUT /api/users/:id  --> Erabiltzailea eguneratu
- DELETE /api/users/:id --> Erabiltzailea ezabatu

Gauza bera reuniones, horarios, ciclos eta beste entitateetarako.

Socket.IO ere gehitu nuen bileren jakinarazpenetarako denbora errealean.

    this.servicioUsuarios.crearUsuario(datuak).subscribe(...)

================================================================================
8. AUTENTIFIKAZIOA
================================================================================

Login sistema localStorage-n oinarritzen da:

1. Erabiltzaileak email eta pasahitza sartzen ditu
2. Backend-ak datu-basean bilatzen du
3. Baliozkoa bada, erabiltzailea "currentUser" gakoarekin localStorage-n gordetzen da
4. Erabiltzailea bere rolaren arabera orrialde desberdinera bideratzen da

AuthGuard bat sortu nuen orrialde babestuetara sarbidea kontrolatzeko. Erabiltzaileak saioa hasi gabe orrialde batera sartzen saiatzen bada, login-era bideratzen da.

9. ITZULPEN SISTEMA (i18n)
================================================================================

Aplikazioak hiru hizkuntza onartzen ditu: Euskara, Gaztelania eta Ingelesa.

Hizkuntza bakoitzarentzat JSON fitxategi bat dago assets/i18n/ karpetan. Adibidez:

    {
      "LOGIN": {
        "TITLE": "Saioa hasi",
        "EMAIL": "Posta elektronikoa"
      }
    }

TranslatePipe bat sortu nuen HTML-n erabiltzeko: {{ 'LOGIN.TITLE' | translate }}

Navbar-an hizkuntza hautatzailea dago erabiltzaileak hizkuntza aldatu ahal izateko.

13. APLIKAZIOA ABIARAZTEA
================================================================================

Backend abiarazteko:

    cd backend
    npm run dev

Frontend abiarazteko:

    cd frontend
    ng serve

Backend-a http://localhost:3000 portuan eta frontend-a http://localhost:4200 portuan exekutatzen dira.
